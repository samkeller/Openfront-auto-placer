# Optional building icons

Place the supplied SVG files in this directory. The GUI currently uses text
labels so it remains dependency-free; this folder reserves a stable location
for icons in a later visual pass.

| Building | Expected asset |
| --- | --- |
| City | `CityIconWhite.svg` |
| Factory | `FactoryIconWhite.svg` |
| Port | `PortIcon.svg` |
| Defense post | `ShieldIconWhite.svg` |
| Missile silo | `MissileSiloIconWhite.svg` |
| S.A.M. launcher | `SamLauncherIconWhite.svg` |
| Atomic bomb | `NukeIconWhite.svg` |
| Warship | `BattleshipIconWhite.svg` or `DestroyerIconWhite.svg` |
| Hydrogen bomb | `MushroomCloudIconWhite.svg` |
| M.I.R.V. | `MIRVIcon.svg` |
